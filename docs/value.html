evolve-anything は何の役に立つか

説明（対応不要）2026-09-05Claude Code を使うが、このプラグインを知らない人向け

背景

目的: AI アシスタント（Claude Code）に同じ注意を何度もしなくて済むようにする
├─ ① あなたが AI を直した発言を、全プロジェクト横断で自動記録する … 稼働中
├─ ② 記録から「ルールに書くべきこと」を毎朝1件ずつ y/n で提案する … 稼働中
├─ ③ 採用した改善が効いたかを週1の数字で見せる … 稼働中（数字は下に） ★いまここ
└─ ④ 効かなかった採用を1コマンドで元に戻す … 稼働中（対象は一部）

位置: 4機能すべて稼働。いまは「数字が本当に効き目を表しているか」を詰めている段階　あなたに: 同じ Claude Code を使っていて、導入の要否を判断する材料が要るため

要点 — AI への「注意」を人が覚えておかなくてよくなる。代わりに毎朝30秒の y/n と、週1で数字を見る

裏付け: 人間の直し発言 45件 が自動で記録済み。直近30日でルールに反映された改善 1件。AI が注意を受けた率（指摘率）は直近週 14.0%（605件中85件）。取得 2026-09-05 09:52 JST、出所は「詳細」。

何が変わるか（あなたの1日の中で）

場面プラグイン無しプラグイン有り
AI が同じ間違いをした毎回その場で注意し、翌週また同じ注意をする注意した発言が自動で記録され、翌朝「ルールに書きますか？」と1件ずつ聞かれる。y で書き込まれる
ルールを書き足した効いたかどうかは体感週1で「注意した率」の推移が出る。効いていなければ数字が下がらない
書き足したルールが逆効果だったどのファイルの何行を直したか思い出して手で戻す採用の一覧から1コマンドで戻す（Inferred 対象は朝の提案経由で採用したものに限る。それ以外は手で戻す）
複数プロジェクトを掛け持ちプロジェクトごとに同じ注意を繰り返す全プロジェクトの記録を横断して「今日どのプロジェクトを見直すべきか」が一覧で出る

役に立たない場面（正直に）

  • AI を直す発言をほとんどしない使い方（短い質問だけ）では記録が貯まらず、提案も出ない
  • 効き目の数字は「注意した率」であって「作業が速くなった」ではない。速さは測っていない
  • 導入しただけでは何も起きない。毎朝の y/n に答える習慣が要る（Inferred 答えないと提案が溜まるだけ）

あなたの対応は不要です

次に動くのは、導入を試すと決めた人。試すなら Claude Code のプラグイン一覧から入れるだけで、記録は無音で始まります。

詳細

数字の出所（取得 2026-09-05 09:52 JST）

~/matsukaze-utils/evolve-anything/bin/evolve-audit --growth
  • 人間の直し発言 45件（total 60 のうち human）: 出力の「Corrections: 45 (human) / 60 (total)」
  • 実際に反映された改善（直近30日）1件。新方式より前の旧記録4件は測定対象外
  • 指摘率 2026-W35: 14.0%（判定605件中 TP 85件・カバレッジ100%）。全プロジェクト合算。分母から除外 3,197件（90日超 1,880件・ホーム起動 1,317件）
  • 記録の捕捉率（人の直し発言を機械が拾えた率）: 21/47 = 44.7%（信頼区間 31.4%–58.8%）。精度 91.3%
  • 直近の採用: 2026-09-02 pillars-before-polish.md / 2026-08-15 spec-keeper

4機能の対応（プラグイン内の呼び名）

  • ① 自動記録 = observe hook（無音）
  • ② 朝の提案 = /evolve-anything:evolve（1件ずつ y/n）
  • ③ 週1の数字 = bin/evolve-audit --growth（戦果ボード）
  • ④ 戻す = bin/evolve-revert --list → --apply

設計上の約束

  • 適用は必ず人間の y/n。無人でルールを書き換えない
  • 表示する数字は分母が揃ったものだけ。揃うまでは「未測定」と出す
