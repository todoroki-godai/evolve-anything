# コミット時のバージョン管理（PJ固有）
bump 時は `.claude-plugin/plugin.json` + `.claude-plugin/marketplace.json` plugins[0].version + `pyproject.toml` project.version + CHANGELOG.md + **`README.md` / `README.ja.md` の Release metadata 行**を同期更新する（README 2件は `check_readme_drift` が検査するので落とすとテストが赤くなる）。bump 後は `claude plugin validate` だけでなく **`python3 -m pytest` を1回通す**（validate は README drift を見ない）。main マージ後に `claude plugin tag --push` で `evolve-anything--v<version>` タグを作成。その後 `bin/evolve-release-sync` を実行してローカル開発環境のプラグインを最新版へ同期する（marketplace は Directory source = ローカル作業ディレクトリを見るため、ローカル main を pull しないと `claude plugin update` が古いバージョンを返す）。最後に `/evolve-anything:docs-refresh` を実行して `docs/site/` を最新化する。
