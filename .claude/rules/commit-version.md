# コミット時のバージョン管理（PJ固有）
bump 時は `.claude-plugin/plugin.json` + `.claude-plugin/marketplace.json` plugins[0].version + `pyproject.toml` project.version + CHANGELOG.md + **`README.md` / `README.ja.md` の Release metadata 行**を同期更新する（README 2件は `check_readme_drift` が検査するので落とすとテストが赤くなる）。bump 後は `claude plugin validate` だけでなく **`python3 -m pytest` を1回通す**（validate は README drift を見ない）。main マージ後に `claude plugin tag --push` で `evolve-anything--v<version>` タグを作成。その後（**参照先の切替 #548 B2 の完了後にだけ有効**。切替前に叩くと live symlink は本番でない木を指す）`bin/evolve-release-sync` を実行して本番のプラグインを最新リリースへ同期する（`claude plugin update` で入った版へ安定パス `~/.claude/plugins/live/evolve-anything` の symlink を張り替える。ローカル main の pull は不要・張り替えはこのスクリプトだけが行う）。**リリースは週1回**（その週に main へ入った変更をまとめて bump → tag → sync）。最新タグが7日より古ければ漏れ（確認手順は PJ memory `reference_maintenance_routine` の週次棚卸し）。最後に `/evolve-anything:docs-refresh` を実行して `docs/site/` を最新化する。
