# 進捗・残タスクは4つの柱で報告する

残タスク・進捗・優先順位は CLAUDE.md「目指すユーザー体験」の柱1〜4（普段=全自動／朝=30秒 y/n／週1=数字／信頼=戻せる）ごとに現状を示し、「どの柱を直接強化するか」で並べる。issue 番号順・作成日順で並べない。
- 各柱の現状は**実測値**で書く。目標文をなぞらない（#376 を自分の報告にも適用する）
- **数値をこの rule にも CLAUDE.md にも書かない**。毎回 `bin/evolve-audit --growth` と `bin/evolve-revert --list` を実行して取る（古い前提の持ち回りは実際に誤報を生んだ・#466）
- **柱は優先順位の物差しであって、やるか否かの取捨ではない**。正しさ・安全・テスト基盤・技術的借金は柱に紐づかなくても「健全性」レーンとして必ず一覧に残す。柱に無理やり紐づけて正当化するのも禁止
- 後回しにするものは「後回しにした」と理由つきで明示する。黙って一覧から消さない
- ボトルネックは柱ごとに1つへ絞る。全部を並列に並べない
